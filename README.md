# WordCraft Web on GitHub Pages

此儲存庫使用 GitHub Actions 部署 [WordCraft](https://github.com/storytold/wordcraft) 官方 WebAssembly 版本至 GitHub Pages。

網站：https://squall021.github.io/wordcraft/

## 部署

- 使用官方發布的 `wordcraft-web-0.5.0.zip`。
- GitHub Repository → Settings → Pages → Source 選擇 **GitHub Actions**。
- 在 Actions → Deploy WordCraft Web 手動執行或提交部署流程。
- 更新前先保留 Git Commit／Tag，並驗證網頁可開啟與 DOCX 匯入／匯出功能。

WordCraft 目前仍屬 Alpha 階段，請使用測試文件驗證功能，並勿將敏感文件上傳到公開 Repository。
